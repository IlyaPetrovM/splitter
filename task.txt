Задача

Создай контейнер использующий ffmpeg и python 
задача контейнера:
1 . получить по FastAPI название файла и параметры 
2. если получено только название файла, то надо брать файл из папки shared_storage
3. В сообщении передаётся параметры: max_duration - максимальная длительность отрезка времени на которую нужно порезать аудио файл (в секундах) или split_parts - количество частей
4. Сервис поднимается на порту 8081
5. Файл режется на части и затем эти части сохраняются в shared_storage/splitted с именем <старое имя файла>_<время начала>__<время окончания>
Нужно чтобы никаких преобразований не делалось
Если передаётся видео файл, то из него просто извлекается аудиодорожка и уже она режется.
